# 🧮 Calculadora Simples em Python

Uma calculadora interativa desenvolvida via terminal em Python para praticar estruturas condicionais e operações matemáticas básicas.

---

## 🚀 Funcionalidades

- [x] Soma (`+`)
- [x] Subtração (`-`)
- [x] Multiplicação (`*`)
- [x] Divisão (`/`)
- [x] Tratamento de erro para divisão por zero

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Python 3](https://www.python.org/)
- **Editor de Código:** [VS Code](https://code.visualstudio.com/)
- **Controle de Versão:** [Git](https://git-scm.com/) / [GitHub](https://github.com/)

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone este repositório ou baixe o código fonte.
3. Abra o terminal na pasta do projeto e execute o comando:

```bash
python calculadora.py
